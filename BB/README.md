# Arena Strike

A browser-based 3D first-person arena shooter. Fight one AI opponent in a neon-lit arena.

## Controls

| Key | Action |
|-----|--------|
| ↑ | Move forward |
| ↓ | Move backward |
| ← | Turn left |
| → | Turn right |
| Space | Shoot |

## Run locally

Serve the folder with any static file server, then open in a browser:

```bash
npx serve .
```

Or open `index.html` directly in a modern browser (Chrome, Edge, Firefox).

## Tech

- [Three.js](https://threejs.org/) for 3D rendering
- No build step required — ES modules via CDN
